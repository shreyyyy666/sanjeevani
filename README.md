# Sanjeevani

Sanjeevani is a clinical research intelligence workspace for paper-first molecular, route, evidence, urgency, patent-guidance, and institutional-review workflows.

## Repository layout

- `frontend/` contains the React client, public landing experience, authenticated workspace pages, reusable UI components, and styling.
- `backend/` contains the Node/tRPC application server, database schema and migrations, private storage helpers, RAG/chemistry contracts, Python intelligence-service boundary, and project documentation.

The managed WebDev deployment remains available from the original project checkpoint. This export is organized for source collaboration and future service deployment.
